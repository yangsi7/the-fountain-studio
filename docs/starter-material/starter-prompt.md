Create a modern Next.js website for a sound healing practitioner targeting self-aware individuals seeking authentic personal growth experiences. The site should convert visitors into session bookings through strategic design and clear calls-to-action.

## Technical Requirements
- **Framework**: Next.js with TypeScript
- **UI Library**: shadcn/ui component library and registry
- **Styling**: Tailwind CSS
- **Languages**: German (DE) and English (EN) with i18n implementation
- **Integrations**: Calendar booking system, WhatsApp contact, future Stripe payment capability

## Design Specifications
**Visual Style**: Modern minimalism with subtle esoteric touches - premium but approachable, not corporate

**Color Palette** (flexible starting point):
- Primary: Rich golden amber (#D4A234) - healing energy, warmth
- Neutral: Warm cream/beige (#F5F1EB) - calming, natural
- Accent: Pure white - clarity, openness
- Text: Black for readability

**Animation**: Subtle micro-interactions that enhance UX without overwhelming

## Site Structure
1. **Home** - Hero section with clear value proposition and booking CTA
2. **Learn More** - Educational content about sound healing approach
3. **Services & Prices** - Clear service offerings with transparent pricing
4. **About** - Personal story emphasizing authenticity and expertise
5. **FAQ** - Address common concerns and objections
6. **Contact/Booking** - Multiple conversion paths (form + WhatsApp)

## Deployment
- We use netlify cli to deploy the website

## Target Audience Considerations
Design for individuals who:
- Are skeptical of commercialized wellness but open to authentic healing
- Prefer understanding root patterns over symptom management
- Value gentle, non-invasive therapeutic approaches
- Seek inner guidance and personal empowerment

## Conversion Strategy
- Multiple booking touchpoints throughout the site
- WhatsApp integration for immediate, personal connection
- Calendar integration for seamless appointment scheduling
- Trust-building elements (testimonials, credentials, authentic messaging)
- Clear, jargon-free explanations of services and benefits

Provide complete code structure, component implementations, and deployment-ready files with responsive design optimized for both desktop and mobile experiences.
